# 🎡 Колесо фортуны

Статичный сайт-рандомайзер: колесо с настраиваемым списком вариантов.
Без сборки и зависимостей — чистые HTML/CSS/JS.

## Запуск

```bash
open index.html
# или локальный сервер:
python3 -m http.server 8000 -d .
```

## Возможности

- Добавление / редактирование (клик по названию) / удаление вариантов
- Ввод нескольких значений сразу через запятую: `Пицца, Суши, Паста`
- Перемешивание и очистка списка
- Опция «удалять победителя после розыгрыша» (для жеребьёвки без повторов)
- История последних 50 розыгрышей
- **Длительность вращения** — ползунок от 1 до 30 секунд; столько же играет музыка
- **Фоновая музыка** — два трека по 20 с: «Деревня дураков» (по умолчанию) и «Ну, погоди!», плюс громкость
- **Состояние в строке запроса** — список, музыка, длительность и настройки кодируются в URL
- Экспорт / импорт списка в JSON
- Светлая и тёмная тема
- Звук: тиканье при вращении + фанфары
- Всё сохраняется в `localStorage`

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Крутить / закрыть окно результата |
| `Esc`   | Закрыть окно результата |

## Структура

```
index.html      разметка
css/style.css   стили и темы (CSS-переменные)
js/app.js       логика: состояние, canvas-колесо, анимация, хранение
music/          аудиофайлы, поставляемые с сайтом
```

## Формат JSON для импорта

```json
["Вариант 1", "Вариант 2", "Вариант 3"]
```

## Параметры строки запроса

Состояние дублируется в адресе страницы и обновляется при каждом изменении.
Открыв такую ссылку, вы получите ту же раскладку — кнопка «Скопировать ссылку» отдаёт готовый адрес.

| Параметр   | Значения | Описание |
|---|---|---|
| `items`    | строки через запятую | список вариантов |
| `duration` | `1`–`30` | длительность вращения в секундах |
| `music`    | `kalambur`, `nupogodi`, `none` | фоновая мелодия |
| `volume`   | `0`–`100` | громкость музыки |
| `remove`   | `1` / `0` | удалять победителя после розыгрыша |
| `sound`    | `1` / `0` | звуковые эффекты (тиканье, фанфары) |
| `theme`    | `light` / `dark` | тема оформления |

Пример:

```
index.html?items=Пицца,Суши,Паста&duration=8&music=circus&volume=60&remove=1&sound=1&theme=dark
```

URL важнее сохранённого состояния: если параметры есть в адресе, они переопределяют `localStorage`.
Некорректные значения безопасно зажимаются в допустимый диапазон.


## Аудио

| Файл | Название в интерфейсе | Источник |
|---|---|---|
| `music/kalambur.m4a`  | Деревня дураков | `derevnja-durakov-soundtrack-kalambur.mp3` |
| `music/nu-pogodi.m4a` | Ну, погоди!     | `na_kolhoznoj_pticeferme.mp3` |

Оба фрагмента по 20 секунд, AAC 128 кбит/с, с фейд-аутом 0.35 с в конце, чтобы стык
петли не щёлкал. «Деревня дураков» взята с начала исходника, «Ну, погоди!» — с 5-й по
25-ю секунду (у неё есть ещё и фейд-ин 0.15 с, так как срез начинается в середине звучания). «Деревня дураков» выбрана по умолчанию, длительность
вращения по умолчанию тоже 20 секунд. Если вращение длиннее — трек зацикливается.

Фрагменты подготовлены штатными утилитами macOS, без ffmpeg:

```bash
afconvert -f WAVE -d LEI16@44100 -c 2 источник.mp3 src.wav   # декодировать
# срез 0–20 с + фейд-аут скриптом на модуле wave из стандартной библиотеки Python
afconvert -f mp4f -d aac -b 128000 cut.wav music/файл.m4a     # закодировать
```

Чтобы добавить ещё трек, положите файл в `music/` и допишите строку в `TRACKS`
в `js/app.js`: `id: { name: 'Название', src: 'music/файл.m4a' }`.

# Безопасность и сопровождение

После выпуска 1.6.3 линия 1.6.x замораживается по функциям. Обновления безопасности,
зависимостей и исправления ошибок выпускаются отдельными patch-версиями.
Уже опубликованные теги не переносятся. `latest` не используется в production.

## Границы доверия

- В интернете доступны только 80/443 Caddy. Порты сайта и коллектора не публикуются.
- `/api/e` открыт для событий. Это недоверенные данные: их нельзя считать доказательством
  реального пользователя, использовать для расчётов денег или выводить как HTML.
- Панель, JSON-отчёты и скрипты панели требуют Basic Auth через HTTPS. Используйте
  уникальный случайный пароль; браузер хранит Basic Auth до закрытия сеанса.
- `TRUST_PROXY=1` допустим только в закрытой Docker-сети за Caddy, который перезаписывает
  `X-Real-IP`. При самостоятельном запуске коллектора оставляйте `TRUST_PROXY=0`.
- Ограничения тела/частоты запросов и соединений уменьшают риск перегрузки одного процесса,
  но не заменяют защиту от распределённой атаки и наблюдение за заполнением диска.

## Данные и секреты

Коллектор сохраняет IP, идентификаторы и тексты вариантов. Тексты могут содержать
персональные данные. Уведомление есть в футере; Do Not Track и `?analytics=off`
отключают отправку. Эти данные не являются полностью анонимными.

`IP_RETENTION_DAYS=0` сохраняет текущий режим бессрочного хранения IP. Положительное
значение очищает только IP при rollup, но не тексты и не остальные события.
Автоматического удаления событий нет. До публичной эксплуатации владелец определяет
срок хранения и контролирует размер базы и резервных копий. Аудит не удаляет старые данные.

`.env`, базы, сертификаты и резервные копии хранятся вне Git. Для `.env` используйте
права `600`, для каталога резервных копий `700`. Никогда не меняйте существующую
`ORG_SALT` при обновлении. Публичные URL содержат варианты: учитывайте это при отправке ссылки.

## Проверки и обновления

```bash
npm ci
npm ci --prefix collector
npm run check:release
npm audit --audit-level=moderate
npm audit --prefix collector --audit-level=moderate
npm test
docker build -t wheel-site:security-audit .
docker build -t wheel-collector:security-audit collector
docker build -t wheel-proxy:security-audit caddy
node scripts/smoke-containers.mjs
```

Нужны Node.js 24+, Docker Compose v2 и браузеры Playwright. Smoke-проверка создаёт
отдельные контейнеры, порты и тома, проверяет HTTPS с временным локальным сертификатом
и удаляет только созданный ею проект. Данные рабочей установки не используются.

CI проверяет историю Git на секреты, npm-зависимости и HIGH/CRITICAL-уязвимости
контейнеров перед публикацией. Образы содержат SBOM и provenance. Результат сканирования
действителен на момент проверки: закреплённые digest и SHA всё равно требуют обновлений.
Dependabot открывает предложения ежемесячно; автоматическое слияние не настроено.

`wheel-proxy` — Caddy 2.11.4 со стандартными модулями, собранная Go 1.27.1 с
исправленными зависимостями из `caddy/go.mod` и `go.sum`. Это собственная сборка,
поэтому обновления Caddy/Go проверяются и выпускаются вместе с приложением.

Об обнаруженной уязвимости сообщайте владельцу проекта приватно. Не прикладывайте
публично действующие пароли, `.env`, реальные списки или дампы SQLite.

Процедура выпуска и отката: [docs/release-freeze.md](docs/release-freeze.md).

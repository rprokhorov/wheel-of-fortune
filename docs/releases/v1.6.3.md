## Что изменилось

- Исправлен сохранённый XSS в подсказках графиков аналитики. Панель использует отдельный JS-файл и Content Security Policy без встроенных скриптов.
- Коллектор проверяет URL, формат и размер пачек, источник браузерных запросов; ограничивает попытки входа, соединения и объём выдачи сессии. Пароли с двоеточиями поддерживаются полностью.
- Обновлён geoip-lite до 2.0.3; коллектор и CI переведены на Node.js 24. Версии пакетов, базовых образов и GitHub Actions закреплены.
- Добавлен `wheel-proxy`: Caddy 2.11.4 пересобрана на Go 1.27.1 с исправленными зависимостями. В рабочем образе коллектора удалены ненужные менеджеры пакетов.
- Сайт и коллектор работают без root, файловые системы контейнеров доступны только для чтения. Базы и секреты исключены из Docker-контекстов и Git.
- URL со списками исключены из access log; отказ `analytics=off` сохраняется при изменениях и перезагрузке страницы.
- Публикация зависит от тестов, проверки секретов, npm audit и сканирования контейнеров. Добавлены описание границ безопасности и порядок обновления/отката.

Результаты подготовки и ограничения проверки: [аудит безопасности](../security-audit-2026-09-23.md).

## Обновление

Требуется резервная копия SQLite и `.env`. Для существующего тома один раз смените владельца на UID/GID 1000, затем пересоздайте **все четыре** сервиса: изменены настройки Caddy и порт сайта внутри Docker-сети.
Точные команды и откат приведены в [инструкции](../release-freeze.md). `ORG_SALT` сохраняется, схема данных совместима с 1.6.2.
